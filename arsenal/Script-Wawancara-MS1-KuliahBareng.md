## 1. Cara Membaca Script Ini

### 1.1 Simbol

| Simbol | Arti |
|---|---|
| 🗣️ | Kalimat yang **diucapkan** pewawancara (boleh disesuaikan gaya bicara, maknanya jangan diubah) |
| 🔍 | Pertanyaan **probing**, dipakai jika jawaban belum cukup dalam |
| 👂 | Apa yang perlu **didengarkan/dicatat** dari jawaban (tidak diucapkan) |
| 👀 | Instruksi **observasi artefak** |
| ⭐ | Pertanyaan **prioritas**; wajib ditanyakan walau waktu mepet |
| ⏭️ | Pertanyaan **opsional**; lewati jika waktu kurang |
| ➡️ | Kalimat **transisi** antar-bagian |
| ⏱️ | Anggaran waktu |

### 1.2 Tujuan tiap bagian (untuk diingat pewawancara)

| Bagian | Menghasilkan data untuk |
|---|---|
| Profil Digital | Persona: device, aplikasi, kebiasaan |
| FRS terakhir | Swimlane (urutan P, decision), UG1/UG4/UG6 |
| Kredibilitas informasi | M1, UX goal trustworthy |
| Kesulitan perkuliahan | Swimlane P10–P13, UG2 |
| Pemantauan nilai | UG5, M5 |
| Berbagi informasi | UG3, M4 |
| Deep-Dive | Detail User Task, pain point, workaround, kutipan |
| Observasi artefak | Bukti visual, langkah kerja nyata, evidence lampiran |

### 1.3 Aturan emas (baca sebelum sesi pertama)

1. **Tanyakan kejadian nyata terakhir**, bukan kebiasaan umum. "Ceritakan terakhir kali…" lebih baik dari "Biasanya kamu…".
2. **Jangan sebut ide aplikasi kita** sebelum penutup. Kalau informan bertanya "ini buat bikin aplikasi ya?", jawab: *"Kami masih di tahap memahami masalah dulu, belum ada solusi. Makanya pengalamanmu penting banget."*
3. **Jangan pernah bertanya** "fitur apa yang kamu mau?" atau "kamu bakal pakai aplikasi X nggak?".
4. **Jangan menyimpulkan untuk informan.** ❌ "Berarti kamu kesel ya?" ✅ "Gimana rasanya waktu itu?"
5. **Jangan membela atau mengoreksi** pendapat informan, termasuk soal dosen atau jurusan tertentu.
6. **Diam 3 detik** setelah informan selesai bicara. Sering muncul cerita tambahan.
7. **Catat timestamp** untuk kutipan bagus, format `[mm:ss]`.
8. **Nama dosen yang disebut informan tidak dicatat** di ringkasan. Tulis "Dosen X matkul Y".

## 2. Persiapan Sebelum Wawancara

### 2.1 H-1 (sehari sebelum)
- [ ] Jadwal & lokasi/tautan meeting sudah dikonfirmasi ke informan
- [ ] Baca ulang script modul domainmu minimal sekali dengan suara pelan
- [ ] Siapkan file ringkasan kosong `I0x_<inisial>.docx` di `02_Ringkasan_Wawancara`
- [ ] Isi baris informan di Registry tab `Informan` (kode, segmen, jadwal)

### 2.2 H-0 (30 menit sebelum)
- [ ] Baterai HP ≥ 50%, memori kosong ≥ 1 GB
- [ ] Uji rekaman 10 detik (tatap muka: aplikasi perekam suara; online: fitur rekam Zoom/Meet/Discord **dan** perekam HP sebagai cadangan)
- [ ] Mode "Jangan Ganggu" aktif
- [ ] Lembar Catatan Cepat (Bagian 14) terbuka/tercetak
- [ ] Siapkan minuman/snack kecil untuk informan (opsional, tatap muka)

### 2.3 Lokasi
- **Tatap muka:** tempat yang cukup tenang agar rekaman jelas (hindari kantin saat jam makan siang). Duduk bersebelahan/menyerong, bukan berhadapan seperti interogasi.
- **Online:** minta informan memakai laptop jika memungkinkan, karena observasi artefak lebih mudah lewat *share screen*.

## 3. Script Rekrutmen & Screening

### 3.1 Pesan ajakan (chat)

> Halo `[nama]`! Aku `[namamu]`, `[prodi/angkatan]`. Aku lagi ngerjain tugas besar matkul Interaksi Manusia Komputer, dan butuh ngobrol sekitar **30 menit** sama mahasiswa ITB soal **pengalaman ngurus FRS, cari info matkul, ngerjain tugas, dan ngatur rencana studi**. Nggak ada jawaban benar/salah, murni cerita pengalaman. Bisa tatap muka atau online.
>
> Kalau berkenan, boleh aku tanya satu hal dulu buat mastiin kamu cocok sama kriteria kami? 🙏

### 3.2 Pertanyaan screening (kirim setelah dibalas)

| Kode | Pewawancara | Pertanyaan screening (harus dijawab "ya") | Data tambahan yang ditanyakan |
|---|---|---|---|
| I1, I2 | A | "Semester ini kamu baru pertama kali FRS di prodi, dan sempat cari info soal matkul/dosen sebelum FRS?" | Angkatan, prodi |
| I3, I4 | B | "Kamu pernah atau sedang ambil matkul pilihan di luar prodi, atau minor?" | Angkatan, prodi, matkul luar prodi apa |
| I5, I6 | C | "Semester ini atau kemarin, kamu cukup sering nanya soal tugas/materi ke grup atau teman?" | Angkatan, prodi |
| I7, I8 | D | "Kamu cukup sering ditanya adik tingkat soal matkul atau tugas?" | Angkatan, prodi, peran (asisten/mentor/pengurus) |
| I9 | E | "Waktu TPB, kamu memantau atau menghitung IP sendiri, misalnya buat persiapan penjurusan?" | Angkatan, prodi |
| I10 | E | "Kamu sedang atau baru saja menghitung sisa SKS atau menyusun matkul supaya bisa lulus tepat waktu?" | Angkatan, prodi |

Setelah "ya": cek aturan sebaran di Registry (≥ 4 fakultas, ≥ 3 angkatan, maks. 3 dari STEI, dua informanmu beda prodi). Jika tidak memenuhi, cari kandidat lain dengan sopan: *"Makasih banyak! Kebetulan kuota prodi itu sudah terisi, nanti kalau butuh aku kabarin lagi ya."*

### 3.3 Pesan konfirmasi jadwal

> Makasih banyak, `[nama]`! Kita ngobrol **`[hari, tanggal]` jam `[jam]`** di **`[lokasi/link]`** ya. Kalau boleh, obrolannya nanti aku rekam audionya buat catatan tugas saja, nama kamu nggak akan muncul di presentasi. Kalau ada perubahan jadwal kabarin aja 🙌

## 4. Pembuka

⏱️ **3 menit**

### 4.1 Salam & tujuan

🗣️ *"Halo `[nama]`, makasih banyak udah mau ngeluangin waktu. Aku `[namamu]` dari `[prodi/angkatan]`."*

🗣️ *"Jadi kelompok kami lagi ngerjain tugas besar Interaksi Manusia Komputer. Kami lagi riset tentang **gimana pengalaman mahasiswa ITB waktu ngambil keputusan akademik dan ngejalanin perkuliahan**, misalnya waktu FRS, nyari info matkul, ngerjain tugas, sampai ngatur rencana studi."*

🗣️ *"Nggak ada jawaban benar atau salah. Justru yang paling kami butuhin itu cerita jujur, termasuk hal-hal yang nyebelin atau ribet. Kamu juga nggak lagi dinilai kok, yang kami pelajari itu pengalamannya, bukan orangnya."*

### 4.2 Consent

🗣️ *"Ngobrolnya sekitar 30 menit. Boleh aku **rekam audionya**? Rekamannya cuma dipakai kelompok kami buat nyatet, **nama kamu nggak akan muncul** di presentasi, dan rekamannya bakal dihapus setelah nilai tugasnya keluar."*

👂 Tunggu jawaban eksplisit "boleh". Jika menolak: *"Oke, nggak masalah, aku catat manual aja ya."* → catat lebih detail, tulis "Consent rekam: N".

🗣️ (setelah rekaman mulai) *"Oke, rekaman udah jalan. Buat catatan, sekarang `[hari, tanggal]`, dan kamu setuju obrolan ini direkam ya?"*

👂 Informan menjawab "setuju" di rekaman → ini bukti consent.

🗣️ *"Kalau ada pertanyaan yang nggak nyaman, bilang aja skip ya. Kamu juga boleh berhenti kapan aja."*

### 4.3 Data diri singkat

🗣️ *"Sebelum mulai, boleh sebutin angkatan, prodi, sama sekarang semester berapa?"*

🗣️ ⏭️ *"Kamu asli Bandung atau merantau?"* (opsional, jangan dipaksa)

👂 Catat: angkatan, prodi/fakultas, semester, perantau (Y/N/tidak disebut).

➡️ *"Oke, aku mulai dari hal yang ringan dulu ya."*

## 5. Modul Inti — Semua Informan

⏱️ **12 menit total.** Semua informan I1–I10 mendapat pertanyaan yang sama agar data bisa dibandingkan.

### Inti-1 — Profil Digital & Keseharian
⏱️ 2 menit

**⭐ Inti-1a**
🗣️ *"Buat urusan kuliah, device apa yang paling sering kamu pakai, HP, laptop, atau tablet? Masing-masing biasanya dipakai buat apa?"*

🔍 *"Kalau lagi di sela kelas atau di jalan, biasanya buka apa?"*

👂 Device utama, konteks pemakaian (mobile vs laptop), situasi.

**⭐ Inti-1b**
🗣️ *"Aplikasi apa aja yang hampir tiap hari kamu buka buat urusan kuliah?"*

🔍 *"Kira-kira kamu ikut berapa grup chat yang ada hubungannya sama kuliah? Mana yang paling aktif?"*
🔍 *"Ada aplikasi atau website buat kuliah yang pernah kamu coba tapi akhirnya berhenti dipakai? Kenapa berhenti?"*

👂 Nama aplikasi (WA, Line, Discord, Notion, Google Sheets, Edunex, SIX, dll. **sesuai yang disebut**), jumlah grup, alasan berhenti memakai aplikasi (bahan UX goal & risiko adopsi).

➡️ *"Oke, sekarang aku mau minta kamu cerita soal FRS semester ini."*

---

### Inti-2 — FRS Terakhir
⏱️ 3 menit · **Sumber utama swimlane. Minta urutan langkah.**

**⭐ Inti-2a**
🗣️ *"Coba ceritain FRS semester ini dari awal sampai disetujui. Mulai kapan kamu mulai mikirin mau ambil apa, terus langkahnya apa aja, sampai akhirnya beres?"*

🔍 *"Dari mana kamu tahu matkul apa yang wajib atau bisa diambil?"*
🔍 *"Ada momen kamu ragu nggak? Ragu soal apa?"*
🔍 *"Waktu ragu itu, kamu ngapain? Tanya siapa?"*
🔍 *"Ada revisi dari dosen wali? Kenapa? Terus kamu ngapain?"*
🔍 *"Dari mulai mikirin sampai disetujui, kira-kira makan waktu berapa lama?"*

👂 **Urutan langkah** (tulis bernomor), **siapa pelakunya** (mahasiswa/kating/dosen wali/sistem), **titik keputusan**, dokumen yang dipakai (kurikulum, pedoman), durasi, emosi.

👂 Validasi fakta: seberapa bebas memilih kelas/dosen? Bagaimana alur persetujuan dosen wali? (**jangan menggiring**, dengarkan saja; jika tidak muncul, tanyakan di Deep-Dive B atau secara netral: *"Waktu pilih kelas di SIX, kamu bisa milih sendiri atau udah ditentukan?"*)

➡️ *"Tadi kamu sempat nyebut dapat info dari `[sumber yang disebut]`. Aku mau tanya soal itu."*

---

### Inti-3 — Kredibilitas Informasi
⏱️ 2 menit

**⭐ Inti-3a**
🗣️ *"Coba inget terakhir kali kamu dapat info soal suatu matkul atau dosen, entah dari kating, grup, atau media sosial. Setelah kamu jalanin matkulnya, infonya sesuai kenyataan nggak? Ceritain."*

🔍 *"Kalau nggak sesuai, bedanya di mana? Dampaknya ke kamu apa?"*
🔍 *"Kalau sesuai, kenapa kamu percaya sama info itu dari awal?"*

**Inti-3b**
🗣️ *"Kalau ada dua orang bilang hal yang beda soal matkul atau dosen yang sama, biasanya gimana kamu mutusin mau percaya yang mana?"*

👂 Kriteria kepercayaan (kedekatan, angkatan, jumlah orang yang bilang, bukti, recency), dampak info salah.

➡️ *"Sekarang loncat ke waktu kuliah udah jalan ya."*

### Inti-4 — Kesulitan Saat Perkuliahan
⏱️ 2 menit

**⭐ Inti-4a**
🗣️ *"Ceritain terakhir kali kamu bingung soal tugas atau materi kuliah. Apa yang kamu lakuin dari awal sampai akhirnya dapat jawaban, atau malah nggak dapat?"*

🔍 *"Sebelum nanya, sempat nyari dulu nggak? Di mana?"*
🔍 *"Nanya ke siapa, lewat mana? Kenapa ke situ?"*
🔍 *"Berapa lama sampai dapat jawaban yang bikin kamu paham?"*

👂 Langkah (cari dulu → tanya), kanal, jumlah tempat yang ditanya, waktu tunggu, apakah jawaban disimpan.

➡️ *"Oke, sekarang soal nilai."*

### Inti-5 — Pemantauan Nilai & Rencana Studi
⏱️ 2 menit

**⭐ Inti-5a**
🗣️ *"Waktu nilai semester kemarin keluar, habis lihat nilainya kamu ngapain? Ada yang kamu hitung atau catat?"*

🔍 *"Pakai apa ngitungnya? Spreadsheet, kalkulator, lihat di SIX aja, atau nggak dihitung?"*
🔍 *"Pernah salah hitung, atau kaget sama IPK atau jumlah SKS-mu? Ceritain."*
🔍 *"Kamu punya gambaran nggak mau ambil matkul apa aja sampai lulus? Disimpan di mana gambaran itu?"*

👂 Ada/tidaknya kebiasaan menghitung, tools, alasan (target, penjurusan, beasiswa, lulus tepat waktu), kesalahan yang pernah terjadi.

## 6. Modul Deep-Dive A — Pencari Info Matkul & Dosen

**Informan:** I1, I2 · **Pewawancara:** A · ⏱️ **12 menit**
**Menghasilkan data untuk:** UG1, UT1.1, UT1.2, M1, M2, UsG1, UxG1

**⭐ A1 — Info yang dicari**
🗣️ *"Dari matkul-matkul semester ini, mana yang paling bikin kamu ragu sebelum FRS?"*
🗣️ *"Buat matkul itu, info apa aja yang kamu cari sebelum mutusin? Coba urutin dari yang paling penting buat kamu."*

🔍 *"Kenapa `[info teratas]` paling penting?"*
🔍 *"Soal dosennya, info apa yang kamu pengen tahu?"*

👂 Jenis info (beban tugas, sistem penilaian, gaya mengajar, tingkat kesulitan, kehadiran, ujian, jadwal) dan prioritasnya.

**⭐ A2 — Proses mencari**
🗣️ *"Ceritain dari mana aja kamu dapat info itu. Urut dari yang pertama kamu lakuin."*

🔍 *"Total waktu yang kamu habisin buat nyari info kira-kira berapa lama?"*
🔍 *"Kamu nyarinya pakai HP atau laptop? Di mana, lagi ngapain?"*

👂 **Urutan langkah** untuk UT1.1, sumber, waktu, konteks.

**⭐ A3 — Info yang gagal didapat**
🗣️ *"Ada info yang sebenarnya kamu butuh tapi nggak berhasil kamu dapetin? Kenapa nggak dapat?"*

🔍 *"Terus akhirnya kamu mutusin berdasarkan apa?"*

**A4 — Konflik informasi**
🗣️ *"Pernah dapat info yang saling bertentangan soal matkul yang sama? Ceritain gimana kamu nyikapinnya."*

👂 Strategi menilai kredibilitas → UT1.2, UxG6.

**⭐ A5 — Ekspektasi vs kenyataan**
🗣️ *"Sekarang kuliahnya udah jalan beberapa minggu. Apa yang beda dari yang kamu bayangin sebelum FRS?"*

🔍 *"Kalau dari awal kamu tahu itu, keputusanmu bakal beda nggak? Kenapa?"*
🔍 *"Dampaknya ke kamu apa? Waktu, nilai, perasaan?"*

👂 Konsekuensi nyata → bukti kuat untuk M2.

**⭐ A6 — Sungkan bertanya**
🗣️ *"Waktu nyari info, ada nggak orang yang sebenarnya pengen kamu tanya tapi nggak jadi? Kenapa?"*

👂 Faktor sosial: belum kenal kating, sungkan, takut ganggu → persona PR1, UxG3.

**👀 A7 — Observasi artefak**
🗣️ *"Boleh tunjukin chat, postingan, atau catatan yang kamu pakai waktu nyari info matkul itu? Nama orang dan hal pribadinya nanti aku blur kok."*

👀 Perhatikan & catat:
- Bagaimana informan **menemukan kembali** chat/postingan tersebut (langsung ingat di mana, scroll, pakai search?)
- Berapa lama sampai ketemu, apakah gagal menemukan
- Bentuk informasinya (panjang, terstruktur/tidak, tanggal)

👀 Ambil screenshot/foto layar (dengan izin). Beri nama file `I0x_artefak_1`.

Jika informan menolak: *"Nggak apa-apa kok."* → lanjut ke penutup.

➡️ Lanjut ke **Bagian 11 Penutup**.

## 7. Modul Deep-Dive B — Jelajah & Bandingkan Matkul

**Informan:** I3, I4 · **Pewawancara:** B · ⏱️ **12 menit**
**Menghasilkan data untuk:** UG4, UT4.1, UT4.2, M1, M2, M6, UsG2, UsG6, UxG2

**⭐ B1 — Mengerucutkan kandidat**
🗣️ *"Ceritain waktu kamu milih matkul di luar prodi `[matkul yang disebut saat screening]`. Awalnya ada berapa kandidat, dan gimana kamu ngerucutinnya sampai tinggal yang diambil?"*

🔍 *"Kandidatnya kamu tahu dari mana? Daftar matkulnya kamu lihat di mana?"*
🔍 *"Ada matkul yang langsung kamu coret? Kenapa?"*

👂 Sumber daftar matkul (UT4.1), jumlah kandidat, alasan eliminasi.

**⭐ B2 — Atribut yang dibandingkan**
🗣️ *"Waktu ngebandingin kandidat, apa aja yang kamu pertimbangin?"*

🔍 Jika jawaban sempit, tawarkan **tanpa menggiring**: *"Selain itu, ada hal lain yang ikut kamu pikirin?"*
🔍 *"Dari semua itu, mana yang paling menentukan?"*

👂 SKS, jadwal/bentrok, beban, dosen, relevansi karier/minat, prasyarat, peluang nilai, teman yang ikut ambil. **Catat urutan prioritas.**

**⭐ B3 — Tempat membandingkan**
🗣️ *"Proses ngebandingin itu kamu lakuin di mana? Di kepala aja, catatan HP, spreadsheet, atau ngobrol sama teman?"*

🔍 *"Kalau kandidatnya lebih dari tiga, ribet nggak? Bagian mana yang ribet?"*

👂 Tools & kerepotan → UsG2 (efficiency).

**⭐ B4 — Kebebasan memilih (validasi fakta)**
🗣️ *"Waktu FRS di SIX, seberapa bebas kamu sebenarnya bisa milih kelas atau dosennya? Apa aja yang ngebatasin?"*

🔍 *"Pernah nggak dapat kelas yang diinginkan? Terus gimana?"*

👂 **Penting untuk reframe UG1/UG4.** Catat detail apa adanya.

**B5 — Penyesalan / kesempatan terlewat**
🗣️ *"Ada matkul pilihan yang kamu sesali, atau yang kamu lewatin terus belakangan nyesel karena ternyata bagus? Ceritain."*

🔍 *"Kalau dilihat lagi, info apa yang waktu itu kurang?"*

**B6 — Frekuensi & memorabilitas**
🗣️ *"Proses milih matkul kayak gini kamu lakuin berapa kali setahun? Tiap kali FRS, kamu masih ingat cara dan pertimbangan yang dulu, atau mulai dari nol lagi?"*

👂 Bukti untuk UsG6 (memorability).

**⏭️ B7 — Beban per semester**
🗣️ *"Waktu nyusun kombinasi matkul satu semester, kamu mikirin total beratnya juga nggak, bukan cuma total SKS? Gimana caranya?"*

👂 Bukti M6 (info beban tidak terhubung dengan perencanaan).

**👀 B8 — Observasi artefak**
🗣️ *"Boleh tunjukin catatan kandidat matkul atau halaman FRS kamu? Nama dan nilai aku blur."*

👀 Perhatikan & catat:
- Bentuk catatan kandidat (daftar, tabel, screenshot, chat ke diri sendiri)
- Kolom/atribut yang ada di catatan tersebut
- Minta informan **menjelaskan sambil menunjuk**: "Ini kenapa dicoret?"

👀 Screenshot → `I0x_artefak_1`.

➡️ Lanjut ke **Bagian 11 Penutup**.

## 8. Modul Deep-Dive C — Bertanya Soal Tugas/Materi

**Informan:** I5, I6 · **Pewawancara:** C · ⏱️ **12 menit**

| Emosi | "Gimana rasanya waktu itu?" |
| Konsekuensi | "Dampaknya ke kamu apa?" · "Kalau itu nggak terjadi, bedanya apa?" |
| Frekuensi | "Itu sering kejadian atau cuma sekali?" |
| Workaround | "Ada cara lain yang pernah kamu coba?" · "Gimana kamu ngakalinnya?" |
| Klarifikasi istilah | "Maksudnya `[istilah]` itu gimana?" |

| Keluar dari opini umum | "Itu pengalaman kamu sendiri atau cerita orang?" |

### 12.1 Pertanyaan yang **dilarang** & penggantinya

| ❌ Jangan | Kenapa | ✅ Ganti dengan |
|---|---|---|
| "Kamu setuju nggak kalau info matkul itu susah dicari?" | Leading | "Gimana pengalamanmu nyari info matkul?" |
| "Fitur apa yang kamu butuhin?" | User bukan desainer; jawaban hipotetis | "Apa yang paling bikin repot waktu …?" |

| "Kenapa kamu nggak nanya aja ke kating?" | Menghakimi | "Waktu itu apa yang kamu pertimbangin sebelum nanya?" |
| Dua pertanyaan sekaligus ("dari mana dan kenapa?") | Informan menjawab salah satu | Tanya satu per satu |

## 13. Menangani Situasi Sulit

| Situasi | Yang dilakukan |
|---|---|
| **Informan menjawab sangat singkat** | Pakai "Bisa kasih contoh kejadian terakhirnya?" Beri jeda diam. Jangan beralih ke pertanyaan berikut terlalu cepat. |
| **Informan terlalu panjang / keluar topik** | Tunggu jeda, lalu: *"Menarik banget. Aku balik sedikit ke `[topik]` ya, tadi kamu sempat bilang `[kata kunci]`…"* |
| **Waktu tersisa 10 menit tapi Modul Inti belum selesai** | Lewati semua ⏭️ dan pertanyaan Inti non-⭐. Deep-Dive: ajukan hanya ⭐ + observasi. Penutup: T1, T4, T5. |
| **Informan menjelekkan dosen/orang tertentu** | Jangan menanggapi penilaiannya. Arahkan ke pengalaman: *"Dampaknya ke cara kamu belajar gimana?"* Jangan catat nama dosen. |
| **Informan terlihat tidak nyaman/emosional** (mis. cerita nilai buruk, mengulang matkul) | *"Makasih udah mau cerita. Kalau mau skip bagian ini, nggak apa-apa banget."* Beri pilihan, jangan menggali lebih jauh. |
| **Informan balik bertanya pendapatmu** | *"Aku penasaran sama pendapatmu dulu. Nanti di akhir kita bisa ngobrol."* |
| **Informan menebak "ini buat bikin aplikasi ya?"** | *"Kami masih tahap memahami masalah, belum ke solusi. Makanya ceritamu penting."* |
| **Informan menolak observasi artefak** | *"Nggak apa-apa kok."* Ganti dengan: *"Boleh ceritain aja, isinya kira-kira kayak gimana?"* |
| **Rekaman gagal di tengah sesi** | Jangan panik. Beri tahu informan, lanjutkan dengan catatan manual lebih detail, segera tulis ringkasan setelah sesi. |
| **Online: koneksi putus** | Hubungi lewat chat, lanjutkan dari pertanyaan terakhir. Jika tidak bisa lanjut dan data < 60%, jadwalkan ulang 15 menit atau pakai informan cadangan. |
| **Informan ternyata tidak cocok segmen** (baru ketahuan di tengah) | Selesaikan Modul Inti dengan sopan (datanya tetap berguna). Catat sebagai `I11+`, cari informan pengganti untuk segmen tersebut. |
| **Jawaban informan bertentangan dengan hipotesis kelompok** | **Bagus.** Gali lebih dalam: "Kenapa menurutmu itu nggak jadi masalah?" Catat di bagian "Kejutan" template ringkasan. |
